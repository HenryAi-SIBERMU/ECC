# Fakta Data: PDRB Sektoral (Bab 1.1)

Dokumen ini memetakan seluruh kolom metrik dari dataset Produk Domestik Regional Bruto (PDRB) Sektoral yang diambil dari API BPS (Sistem SIMDASI). Data ini digunakan untuk membuktikan terjadinya transisi atau dominasi struktur ekonomi daerah menuju *Sektor Ekstraktif* (Sub-bab 1.1) serta Dekomposisi PDRB Kabupaten (Sub-bab 1.2).

---

## 1. Dataset PROCESSED: PDRB Sektoral Provinsi (2016-2024)
**Nama File:** `sulawesi_pdrb_sektoral_2016_2024.csv`  
**Deskripsi:** Agregasi nilai PDRB (Miliar Rupiah) atas dasar harga berlaku (ADHB) untuk seluruh 17 Lapangan Usaha KBLI 2020 di 6 Provinsi se-Sulawesi.

### Tabel Kamus Kolom Dataset (Data Dictionary)

| Nama Kolom di CSV | Penjelasan Teknis (Metodologi) | Penjelasan Bahasa Bayi (Awam) |
| :--- | :--- | :--- |
| `provinsi` | Entitas administratif level 1 di wilayah regional Sulawesi. | Nama Provinsi (Misal: Sulawesi Tengah, Sulawesi Tenggara). |
| `tahun` | Periode waktu sensus ekonomi ADHB (Tahun 2016 hingga 2024). | Tahun pencatatan nilai ekonomi daerah. |
| `sektor_kode` | Kode Abjad KBLI 2020 resmi dari BPS (Kategori A s.d. U). | Kode resmi sektor usaha (Misal: A untuk Pertanian, B untuk Tambang). |
| `sektor_nama` | Nama Kategori Lapangan Usaha BPS KBLI 2020. | Bidang pekerjaan atau industri utama. |
| `nilai_miliar_rp` | Nilai tambah bruto sektoral dalam satuan Miliar Rupiah (Atas Dasar Harga Berlaku). | Uang total yang dihasilkan oleh sektor tersebut (dalam satuan Miliar Rupiah). |
| `nilai_triliun` | Transformasi data `nilai_miliar_rp / 1000` untuk memudahkan visualisasi agregat besar. | Uang total yang dihasilkan dalam skala yang lebih besar (Triliun Rupiah). |

## 2. Dataset PROCESSED: PDRB Sektoral Kabupaten (2016-2024)
**Nama File:** `sulawesi_pdrb_sektoral_kabupaten_2016_2024.csv`  
**Deskripsi:** Agregasi nilai PDRB tingkat Kabupaten/Kota (khususnya untuk *deep-dive* kawasan smelter seperti Morowali dan Konawe) dengan struktur kolom yang identik dengan data tingkat provinsi.

### Tabel Kamus Kolom Dataset Tambahan

| Nama Kolom di CSV | Penjelasan Teknis (Metodologi) | Penjelasan Bahasa Bayi (Awam) |
| :--- | :--- | :--- |
| `kabupaten_kota` | Entitas administratif level 2 (Kabupaten/Kota) tempat PDRB dicatatkan. | Nama Daerah Kabupaten/Kota (Misal: Kab. Morowali, Kab. Konawe). |

---

## 3. Fakta Data: Matriks Pengelompokan Klaster Ekonomi (Legal Supply-Chain)

Berdasarkan metodologi pada *Bagan Alur 1.1*, data PDRB KBLI yang terdiri dari 17 Kategori dilebur menjadi **3 Klaster Utama** untuk diuji di level analisis ekonomi regional. Berikut adalah fakta pemetaan datanya:

| Klaster Metodologi Celios | Komponen Pembentuk (KBLI BPS) | Justifikasi Fakta Data |
| :--- | :--- | :--- |
| **Sektor Ekstraktif** | Kategori B (Pertambangan) + Kategori C (Industri Pengolahan / Smelter) + Kategori D (Pengadaan Listrik / PLTU Captive). | Tiga sektor ini secara regulasi membentuk satu kesatuan rantai pasok industri nikel terintegrasi (berdasarkan UU No.3/2020 & Perpres No.112/2022). |
| **Sektor Ekonomi Akar Rumput** | Kategori A (Pertanian, Kehutanan, dan Perikanan). | Sektor tradisional penyerap tenaga kerja lokal terbanyak yang memanfaatkan SDA hayati terbarukan. |
| **Sektor Jasa & Lainnya** | Kategori E hingga U (Sektor Tersier dan Jasa Publik). | Kumpulan 13 sektor penunjang non-ekstraktif seperti konstruksi, perdagangan, dan administrasi pemerintahan. |

> **Kesimpulan Fakta (Validasi):**
> Dashboard Celios menampilkan pergeseran struktur ekonomi (*Structural Shift*) secara akurat tanpa manipulasi angka, karena klasterisasi Sektor Ekstraktif murni menggunakan penjumlahan 3 kolom resmi (Kat B+C+D) yang diekstrak langsung dari API BPS tanpa ada estimasi (*guestimate*) atau ekstrapolasi buatan.

## 4. Rincian 17 Kategori Lapangan Usaha (KBLI 2020)

Untuk memfasilitasi transparansi penuh atas *raw data* yang diekstrak dari BPS, berikut adalah daftar lengkap 17 sektor lapangan usaha standar BPS (KBLI 2020) yang tercatat dalam data PDRB:

| Kode Kategori | Nama Lapangan Usaha (Sektor) |
| :---: | :--- |
| **A** | Pertanian, Kehutanan, dan Perikanan |
| **B** | Pertambangan dan Penggalian |
| **C** | Industri Pengolahan |
| **D** | Pengadaan Listrik dan Gas |
| **E** | Pengadaan Air, Pengelolaan Sampah, Limbah dan Daur Ulang |
| **F** | Konstruksi |
| **G** | Perdagangan Besar dan Eceran; Reparasi Mobil dan Sepeda Motor |
| **H** | Transportasi dan Pergudangan |
| **I** | Penyediaan Akomodasi dan Makan Minum |
| **J** | Informasi dan Komunikasi |
| **K** | Jasa Keuangan dan Asuransi |
| **L** | Real Estat |
| **M, N** | Jasa Perusahaan |
| **O** | Administrasi Pemerintahan, Pertahanan dan Jaminan Sosial Wajib |
| **P** | Jasa Pendidikan |
| **Q** | Jasa Kesehatan dan Kegiatan Sosial |
| **R, S, T, U** | Jasa lainnya |
