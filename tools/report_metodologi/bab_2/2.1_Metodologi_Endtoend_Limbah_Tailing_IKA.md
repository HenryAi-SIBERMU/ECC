# Pilar 2: End-to-End Data Pipeline - Dampak Limbah Tailing: Konsentrasi Smelter vs IKA (Bab 2.1)

> **Topik:** Korelasi Spasial-Temporal antara Pemusatan Smelter Nikel, Indeks Kualitas Air (IKA), dan Limbah Tailing.
> **Sumber Data:** 
> 1. Kementerian ESDM MODI (`minerbaone_permits.csv`)
> 2. Laporan Status Lingkungan Hidup KLHK (Indeks Kualitas Air)
> 3. Laporan NGO (AEER, WALHI) untuk Proxy Limbah B3 dan Sungai Tercemar
> **Jalur File Eksekutor:** Berbagai *script* ekstraksi PDF dan agregasi Pandas, berpusat pada `bab2 bismillah.py`.

Dokumen ini memetakan *End-to-End Pipeline* ekstraksi data dan penyatuan (*merging*) untuk menguji hipotesis degradasi kualitas air akibat pemusatan fasilitas smelter. Karena data IKA KLHK terkunci dalam dokumen PDF tahunan dan data empiris limbah B3/tailing tidak dirilis terbuka oleh pemerintah, metodologi ini mendemonstrasikan teknik *Optical Character Recognition* (OCR) dan triangulasi data *proxy* NGO.

## 2. Stage 2: ETL / Ingestion

Berbeda dengan API terstruktur BPS, data lingkungan dan perizinan ditambang dari dokumen *semi-structured*:
- **Indeks Kualitas Air (IKA):** Berasal dari laporan tahunan berformat PDF (*hardcoded table*). Sistem menggunakan pustaka seperti `Camelot` / `PDFPlumber` dengan algoritma *Lattice* (mendeteksi batas tabel grid) untuk mengevakuasi matriks skor IKA per provinsi menjadi `pd.DataFrame`.
- **Fasilitas Smelter:** Data dasar dari CGS dan ESDM direstrukturisasi (*reshape*) dengan menyaring fasilitas khusus "Nikel" di region "Sulawesi".
- **Estimasi Timbulan Limbah:** Tailing nikel yang tidak tercatat di *dashboard* resmi dikalkulasi menggunakan *proxy estimate* dari riset AEER (kalkulasi rasio input nikel mentah berbanding volume tailing/terak (*slag*)).

---

## 3. Stage 3: Preprocessing & Cleaning

Penyelarasan tipe data (*Data Casting*) dilakukan untuk mengizinkan tabel relasional (*Merge*) antar entitas waktu (Tahun) dan entitas ruang (Provinsi).

| Tahap Pembersihan | Kolom Target | Deskripsi Tindakan (Logika Pandas) | Contoh Transformasi |
| :--- | :--- | :--- | :--- |
| **Pembersihan Nama Wilayah** | `Provinsi` | Menghapus spasi (*whitespace*) dan menyelaraskan kapitalisasi agar `pd.merge()` tidak menghasilkan nilai NaN (*Not a Number*). | `"  Sulawesi Tengah "` ➔ `"Sulawesi Tengah"` |
| **Imputasi Nilai Kosong** | `Jumlah_Smelter` | Melakukan operasi `.fillna({"Jumlah_Smelter": 0})` bagi provinsi yang tidak memiliki smelter nikel (seperti Sulawesi Utara/Gorontalo). | `NaN` ➔ `0` |
| **Reshape Panel (Melt)** | `Tahun`, `Indeks Kualitas Air` | Mengubah format kolom tahun yang menyamping (*wide format*) menjadi baris memanjang ke bawah (*long format*). | `(SulTeng, IKA_2020)` ➔ `(SulTeng, 2020, 56.4)` |
| **Normalisasi Skoring** | `IKA` | Membersihkan simbol koma dari PDF Eropa/Indonesia menjadi format float titik (desimal universal standar komputasi). | `"54,23"` ➔ `54.23` |

---

## 4. Stage 4: Triangulasi Empiris & Uji Panel

Setelah data mendarat dalam satu kerangka kerja (*Dataframe Panel*), variabel ini disuntikkan ke dalam modul pengujian inferensial:
1. **Pemusatan Independen (X):** `Jumlah_Smelter` bertindak sebagai pengukur intensitas tekanan ruang (industri).
2. **Dampak Dependen (Y):** Penurunan `Indeks Kualitas Air` sebagai indikator kualitas lingkungan perairan.
3. **Data Spasial Bukti (Ground Truth):** *Dataset* sungai tercemar (`sulawesi_sungai_tercemar.csv`) memvalidasi penurunan skoring IKA dengan data lapangan (misal: "Warna air Teluk Tolo berubah kemerahan akibat erosi limonit/laterit").
